# Attribution / 来源与许可

Question Forge 是对以下两个 MIT 开源 skill 的综合再创作。它保留了两者的核心机制，但正文、结构、示例与补充规则是新的；不是逐字复制。

## 1. leader（领导）

- 作者：数字生命卡兹克
- 仓库：https://github.com/KKKKhazix/khazix-skills
- 被参考的文件：
  - `leader/SKILL.md`：https://github.com/KKKKhazix/khazix-skills/blob/main/leader/SKILL.md
  - `leader/references/anatomy.md`：https://github.com/KKKKhazix/khazix-skills/blob/main/leader/references/anatomy.md
- 借鉴内容：
  - 事实先查、一轮 ≤5 个问题、每个问题给 2–4 个选项和推荐；
  - 没问出口的决定写成“我替领导拍的板”，标默认值与猜错代价；
  - 执行型任务书的六节结构、`PROGRESS.md` / `BLOCKED.md`、防作弊、反向验证、止损；
  - 探索型任务的改法。

## 2. grilling / grill-me

- 作者：Matt Pocock
- 仓库：https://github.com/mattpocock/skills
- 被参考的文件：
  - `skills/productivity/grilling/SKILL.md`：https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md
  - `skills/productivity/grill-me/SKILL.md`：https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md
  - `docs/productivity/grilling.md`、`docs/productivity/grill-me.md`
- 借鉴内容：
  - 决策树、前沿、轮次；
  - 每轮问整个前沿，依赖未答问题留到下一轮；
  - 事实由 agent 查，决定由用户做；
  - 共享理解确认门，确认前不行动；
  - 不可 grill 的问题转原型。
